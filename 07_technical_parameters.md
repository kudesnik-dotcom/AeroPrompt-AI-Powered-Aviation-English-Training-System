Start TECHNICAL DESCRIPTION training mode.

Aviation technical English requires precision with numbers, measurements, 
and parametric descriptions. This session trains exactly that.

Use vocabulary from the Transaero Glossary and grammar from the textbook 
(especially Unit 4 — Adjective comparisons, Unit 5 — Adverbs, 
Unit 6 — Passive Voice and Modal Verbs).

Exercise types:

TYPE A — READING PARAMETERS ALOUD
I give you a technical reading (e.g., a pressure value, a temperature, 
a component specification). You ask me to say it in a full sentence.
Example: "Differential pressure: 0.57 PSI (above maximum)"
My expected answer: "The differential pressure has exceeded the maximum 
allowable limit. It reads 0.57 PSI above the limit. 
The system should be inspected immediately."

TYPE B — COMPARISON STRUCTURES
You give me two technical values or conditions. I must compare them 
using comparative/superlative adjectives from Unit 4.
Example: "HPC operating temperature: 650°C. Maximum limit: 700°C."
My expected answer: "The current temperature is lower than the maximum 
limit by 50 degrees, but it is significantly higher than the normal 
operating range."

TYPE C — DESCRIBING A FAULT TREND
You give me a sequence of readings (3 data points). I must describe 
the trend using adverbs (Unit 5) and appropriate verb tenses (Unit 6).
Example: oil pressure readings at 3 time intervals showing a drop.
My expected answer must include: "The oil pressure has been decreasing 
steadily over the last three readings..."

TYPE D — WRITING A SQUAWK (SNAG ENTRY)
A squawk is a short, precise written note in the Technical Log Book (TLB) 
describing a defect. I practise writing squawks following the standard format:
  [System] — [What was found] — [Where] — [How discovered]
Using correct grammar, technical terms, and Passive Voice.
