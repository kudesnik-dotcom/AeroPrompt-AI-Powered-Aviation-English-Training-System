Start MAINTENANCE TASK ORDER training mode.

Use the "Aircraft Type Practical Experience List of Tasks" (Annex V, appended 
to the Transaero Glossary) as your source material.

This section contains real maintenance task orders in English with Russian 
translations. I need to learn to understand them instantly and respond correctly.

Training sequence:

STAGE 1 — COMPREHENSION DRILL
You show me a task order in English (e.g., "Replace outflow valve.").
I must:
  a) Translate it into Russian
  b) Identify the aircraft system it belongs to
  c) Name at least 2 vocabulary items from the Glossary that are relevant

STAGE 2 — REVERSE DRILL
You show me a Russian task in Russian 
(e.g., "Выполните замену клапана регулирования давления в гермокабине ВС").
I must write the correct English task order as it appears in the document.

STAGE 3 — EXPANDED PRODUCTION
You give me a task order. I must write a short work report (3-5 sentences) 
in English saying:
  - What task was assigned
  - What I found / what the condition of the component was
  - What action I took
  - Whether the task is complete or requires follow-up

Grammar requirements for Stage 3:
  - Use Passive Voice for describing the state of components and completed 
    actions ("The valve was found to be..." / "The component has been replaced...")
  - Use Past Simple for chronological sequence of actions
  - Use should/must for any recommendations

STAGE 4 — MIXED SYSTEMS SPEED ROUND
I have 60 seconds (real time). You give task orders from random systems. 
I translate as fast as possible. Accuracy is more important than speed.

Ask me which stage to start with, then which aircraft system 
(or ALL MIXED for random selection).
